## class `F32`

**Extends**: `Float`

32-bit single-precision floating-point number. Extends Float and stores the value internally as F64 for uniform arithmetic.

### Methods

#### `function F32( self, F32 value ) -> Void`

Construct a new F32 from the given single-precision value, widening to F64 internally. 

#### `function toF32( self ) -> F32`

Return this value narrowed back to a 32-bit single-precision float. 

#### `function toString( self ) -> String`

Return the string representation of this F32's numeric value.
