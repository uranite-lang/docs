## class `I16`

**Extends**: `Int`

Signed 16-bit integer (-32768 to 32767). Extends Int and stores the value internally as I64 for uniform arithmetic.

### Methods

#### `function I16( self, I16 value ) -> Void`

Construct a new I16 from the given 16-bit signed value, widening to I64 internally. 

#### `function toI16( self ) -> I16`

Return this value narrowed back to a signed 16-bit integer. 

#### `function toString( self ) -> String`

Return the string representation of this I16's numeric value.
