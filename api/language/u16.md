## class `U16`

**Extends**: `UInt`

Unsigned 16-bit integer (0 to 65535). Extends UInt and stores the value internally as U64 for uniform arithmetic.

### Methods

#### `function U16( self, U16 value ) -> Void`

Construct a new U16 from the given 16-bit unsigned value, widening to U64 internally. 

#### `function toU16( self ) -> U16`

Return this value narrowed back to an unsigned 16-bit integer. 

#### `function toString( self ) -> String`

Return the string representation of this U16's numeric value.
