## class `Sha256`

SHA-256 hash computation state. Supports incremental hashing via update() calls followed by a final digest() call. The state can be reset for reuse without reallocation.

### Fields

| Name | Type | Access |

| `blockLength` | `I64` | protect |
| `totalBytesLow` | `I64` | protect |
| `totalBytesHigh` | `I64` | protect |
| `roundConstantsAddress` | `I64` | protect |

### Methods

#### `function Sha256( self ) -> Void`

Construct a new SHA-256 hasher with initial hash values per FIPS 180-4 section 5.3.3 and precomputed round constants.

**Complexity**:
- Time: `O(1)`
- Space: `O(1) (360 bytes allocated: 32 state + 64 block + 256 constants)`

#### `function initializeState( self ) -> Void`

Set the eight 32-bit state words to the SHA-256 initial hash values.

#### `function initializeRoundConstants( self ) -> Void`

Store the 64 SHA-256 round constants (first 32 bits of the fractional parts of the cube roots of the first 64 primes) into the constants buffer as big-endian I32 values.

#### `function rightRotate32( self, I64 value, I64 amount ) -> I64`

Perform a 32-bit right rotation.

**Parameters**:

- `value` (`I64`)
- `The 32-bit value to rotate.`
- `amount` (`I64`)
- `Number of bit positions to rotate right.`

**Returns**: `I64` — The rotated 32-bit value.

#### `function processBlock( self ) -> Void`

Process a single 64-byte block through the SHA-256 compression function. Reads the block from self.blockAddress, reads and updates the state at self.stateAddress.

**Complexity**:
- Time: `O(1) (64 rounds, constant)`
- Space: `O(1) (256 bytes for message schedule)`

#### `function update( self, I64 dataAddress, I64 dataLength ) -> Void`

Feed data into the hash computation. Can be called multiple times to hash data incrementally. Internally buffers partial blocks and processes complete 64-byte blocks as they become available.

**Parameters**:

- `dataAddress` (`I64`)
- `Base address of the input data.`
- `dataLength` (`I64`)
- `Number of bytes to process.`

**Complexity**:
- Time: `O(n) where n is dataLength`
- Space: `O(1)`

#### `function updateString( self, String data ) -> Void`

Feed a string into the hash computation. Convenience wrapper that converts the string to a raw address and length internally.

**Parameters**:

- `data` (`String`)
- `The string data to hash.`

**Complexity**:
- Time: `O(n) where n is string length`
- Space: `O(1)`

#### `function digest( self, I64 outputAddress ) -> Void`

Finalize the hash computation and write the 32-byte digest to the output address. Applies FIPS 180-4 padding: a 1-bit, zero padding to 56 bytes mod 64, then the 64-bit message length in bits.

After calling digest(), the hasher state is consumed. Call reset() before reusing.

**Parameters**:

- `outputAddress` (`I64`)
- `Address to write the 32-byte digest.`

**Complexity**:
- Time: `O(1) (at most 2 block compressions for padding)`
- Space: `O(1)`

#### `function hexDigest( self ) -> String`

Finalize the hash and return the digest as a 64-character lowercase hexadecimal string. Consumes the hasher state — call reset() before reusing.

**Returns**: — String:
The 32-byte digest encoded as 64 hex characters.

**Complexity**:
- Time: `O(1)`
- Space: `O(64) for hex output buffer`

#### `function reset( self ) -> Void`

Reset the hasher to its initial state for reuse without reallocation.

**Complexity**:
- Time: `O(1)`
- Space: `O(1)`

#### `function destroy( self ) -> Void`

Free all memory allocated by this hasher. Must not be used after.

**Complexity**:
- Time: `O(1)`
- Space: `O(1)`

## function `sha256`

Compute the SHA-256 hash of dataLength bytes at dataAddress and write the 32-byte digest to outputAddress. Convenience function for single- shot hashing without manual hasher lifecycle management.

**Parameters**:

- `dataAddress` (`I64`)
- `Base address of the input data.`
- `dataLength` (`I64`)
- `Number of bytes to hash.`
- `outputAddress` (`I64`)
- `Address to write the 32-byte digest.`

**Complexity**:
- Time: `O(n) where n is dataLength`
- Space: `O(1)`
