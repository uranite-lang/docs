## class `Sha512`

SHA-512 hash computation state. Supports incremental hashing via update() calls followed by a final digest() call.

### Methods

#### `function Sha512( self ) -> Void`

Construct a new SHA-512 hasher with initial hash values per FIPS 180-4 section 5.3.5 and precomputed round constants.

**Complexity**:
- Time: `O(1)`
- Space: `O(1) (832 bytes allocated: 64 state + 128 block + 640 constants)`

#### `function initializeState( self ) -> Void`

Set the eight 64-bit state words to the SHA-512 initial hash values.

#### `function initializeRoundConstants( self ) -> Void`

Store the 80 SHA-512 round constants (first 64 bits of the fractional parts of the cube roots of the first 80 primes).

#### `function rightRotate64( self, I64 value, I64 amount ) -> I64`

Perform a 64-bit right rotation using unsigned shift semantics.

**Parameters**:

- `value` (`I64`)
- `The 64-bit value to rotate.`
- `amount` (`I64`)
- `Number of bit positions to rotate right.`

**Returns**: `I64` — The rotated 64-bit value.

#### `function logicalRightShift64( self, I64 value, I64 amount ) -> I64`

Perform an unsigned (logical) right shift on a 64-bit value.

**Parameters**:

- `value` (`I64`)
- `The 64-bit value to shift.`
- `amount` (`I64`)
- `Number of bit positions to shift right.`

**Returns**: `I64` — The shifted value with zero-filled high bits.

#### `function processBlock( self ) -> Void`

Process a single 128-byte block through the SHA-512 compression function with 80 rounds.

**Complexity**:
- Time: `O(1) (80 rounds, constant)`
- Space: `O(1) (640 bytes for message schedule)`

#### `function update( self, I64 dataAddress, I64 dataLength ) -> Void`

Feed data into the hash computation incrementally.

**Parameters**:

- `dataAddress` (`I64`)
- `Base address of the input data.`
- `dataLength` (`I64`)
- `Number of bytes to process.`

**Complexity**:
- Time: `O(n) where n is dataLength`
- Space: `O(1)`

#### `function updateString( self, String data ) -> Void`

Feed a string into the hash computation. Convenience wrapper that converts the string to a raw address and length internally.

**Parameters**:

- `data` (`String`)
- `The string data to hash.`

**Complexity**:
- Time: `O(n) where n is string length`
- Space: `O(1)`

#### `function digest( self, I64 outputAddress ) -> Void`

Finalize the hash and write the 64-byte digest. Applies FIPS 180-4 padding: 1-bit, zeros to 112 bytes mod 128, then 128-bit length.

**Parameters**:

- `outputAddress` (`I64`)
- `Address to write the 64-byte digest.`

**Complexity**:
- Time: `O(1) (at most 2 block compressions)`
- Space: `O(1)`

#### `function hexDigest( self ) -> String`

Finalize the hash and return the digest as a 128-character lowercase hexadecimal string. Consumes the hasher state — call reset() before reusing.

**Returns**: — String:
The 64-byte digest encoded as 128 hex characters.

**Complexity**:
- Time: `O(1)`
- Space: `O(128) for hex output buffer`

#### `function reset( self ) -> Void`

Reset the hasher to initial state for reuse.

**Complexity**:
- Time: `O(1)`
- Space: `O(1)`

#### `function destroy( self ) -> Void`

Free all memory allocated by this hasher.

**Complexity**:
- Time: `O(1)`
- Space: `O(1)`
