## class `I32`

**Extends**: `Int`

Signed 32-bit integer. Extends Int and stores the value internally as I64 for uniform arithmetic.

### Methods

#### `function I32( self, I32 value ) -> Void`

Construct a new I32 from the given 32-bit signed value, widening to I64 internally. 

#### `function toI32( self ) -> I32`

Return this value narrowed back to a signed 32-bit integer. 

#### `function toString( self ) -> String`

Return the string representation of this I32's numeric value.
