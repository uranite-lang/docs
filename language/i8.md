## class `I8`

**Extends**: `Int`

Signed 8-bit integer (-128 to 127). Extends Int and stores the value internally as I64 for uniform arithmetic.

### Methods

#### `function I8( self, I8 value ) -> Void`

Construct a new I8 from the given 8-bit signed value, widening to I64 internally. 

#### `function toI8( self ) -> I8`

Return this value narrowed back to a signed 8-bit integer. 

#### `function toString( self ) -> String`

Return the string representation of this I8's numeric value.
