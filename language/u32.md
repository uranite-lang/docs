## class `U32`

**Extends**: `UInt`

Unsigned 32-bit integer (0 to 4294967295). Extends UInt and stores the value internally as U64 for uniform arithmetic.

### Methods

#### `function U32( self, U32 value ) -> Void`

Construct a new U32 from the given 32-bit unsigned value, widening to U64 internally. 

#### `function toU32( self ) -> U32`

Return this value narrowed back to an unsigned 32-bit integer. 

#### `function toString( self ) -> String`

Return the string representation of this U32's numeric value.
