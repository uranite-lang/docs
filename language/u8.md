## class `U8`

**Extends**: `UInt`

Unsigned 8-bit integer (0 to 255). Extends UInt and stores the value internally as U64 for uniform arithmetic.

### Methods

#### `function U8( self, U8 value ) -> Void`

Construct a new U8 from the given 8-bit unsigned value, widening to U64 internally. 

#### `function toU8( self ) -> U8`

Return this value narrowed back to an unsigned 8-bit integer. 

#### `function toString( self ) -> String`

Return the string representation of this U8's numeric value.
