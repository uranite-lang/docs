## function `addrToSession`

Reinterpret a raw memory address as a Session object reference.

Uses inline assembly to cast the integer address back to a Session pointer. The caller must ensure the address points to a valid Session.

**Parameters**:

- `addr` (`I64`)
- `The memory address of a previously stored Session object.`

**Returns**: `Session` — The Session object at the given address.

## class `Session`

An in-memory session that stores key-value string pairs.

Each session is identified by a unique session ID and can hold up to MAX_SESSION_ENTRIES entries. Keys and values are stored as raw pointers in parallel Memory arrays.

### Fields

| Name | Type | Access |
|------|------|--------|
| `sessionId` | `String` | public |
| `keys` | `Memory<I64>` | public |
| `values` | `Memory<I64>` | public |
| `entryCount` | `I64` | public |

### Methods

#### `function Session( self, String sessionId ) -> Void`

Construct a new Session with the given identifier.

Allocates storage for up to MAX_SESSION_ENTRIES key-value pairs.

**Parameters**:

- `sessionId` (`String`)
- `The unique identifier for this session.`

**Complexity**:
- Time: `O(1)`
- Space: `O(1)`

#### `function set( self, String key, String value ) -> Void`

Set a key-value pair in the session.

If the key already exists, its value is updated in place. If the key is new and the session has not reached MAX_SESSION_ENTRIES, the pair is appended.

**Parameters**:

- `key` (`String`)
- `The entry key.`
- `value` (`String`)
- `The entry value.`

**Complexity**:
- Time: `O(n) where n is the number of entries (linear scan for existing key)`

#### `function get( self, String key ) -> String`

Retrieve a value from the session by key.

**Parameters**:

- `key` (`String`)
- `The entry key to look up.`

**Returns**: — String:
The associated value, or empty string if the key is not found.

**Complexity**:
- Time: `O(n) where n is the number of entries`

#### `function remove( self, String key ) -> Void`

Remove a key-value pair from the session.

Uses swap-with-last removal to avoid shifting elements. If the key is not found, this method does nothing.

**Parameters**:

- `key` (`String`)
- `The entry key to remove.`

**Complexity**:
- Time: `O(n) where n is the number of entries (linear scan for key)`

#### `function destroy( self ) -> Void`

Release heap-allocated key and value buffers for this session.

**Complexity**:
- Time: `O(n)`
- Space: `O(1)`

## class `SessionStore`

In-memory store that manages multiple Session instances.

Sessions are created with unique IDs derived from the monotonic clock and stored as raw memory addresses in a flat array. Supports up to MAX_SESSIONS concurrent sessions.

### Fields

| Name | Type | Access |
|------|------|--------|
| `sessions` | `Memory<I64>` | public |
| `sessionCount` | `I64` | public |

### Methods

#### `function SessionStore( self ) -> Void`

Construct a new SessionStore with empty session storage.

Allocates space for up to MAX_SESSIONS session entries.

**Complexity**:
- Time: `O(1)`
- Space: `O(1)`

#### `function createSession( self ) -> Session`

Create a new session with a unique ID derived from the monotonic clock.

The session ID is generated by converting the current monotonic timestamp to a hexadecimal string. The session is stored in the session array if capacity permits.

**Returns**: — Session:
The newly created session.

**Complexity**:
- Time: `O(1)`
- Space: `O(1)`

#### `function getSession( self, String sessionId ) -> ?Session`

Look up an existing session by its session ID.

Performs a linear scan over all stored sessions for a matching ID.

**Parameters**:

- `sessionId` (`String`)
- `The session ID to search for.`

**Returns**: — ?Session:
The matching session, or None if no session with the given
ID exists.

**Complexity**:
- Time: `O(n) where n is the number of active sessions`

#### `function destroy( self ) -> Void`

Release the heap-allocated session storage buffer.

**Complexity**:
- Time: `O(1)`
- Space: `O(1)`
